# 算法可视化教学

一个交互式的算法可视化教学工具，通过动画演示帮助理解数据结构与算法。

## 功能特点

- 🎯 **排序算法**：冒泡排序、快速排序、归并排序等
- 🔍 **查找算法**：二分查找、顺序查找等
- 📚 **线性表**：顺序表、链表的可视化
- 📚 **栈和队列**：栈和队列操作的动画演示
- 🌲 **树结构**：二叉树、 BST 的可视化
- 🔗 **图结构**：BFS、DFS 图遍历演示

## 使用方法

直接在浏览器中打开 `index.html` 文件即可使用。

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)

## 部署

可以使用 GitHub Pages、Vercel、Netlify 等静态网站托管服务部署。

### GitHub Pages 部署

1. 将项目推送到 GitHub 仓库
2. 在仓库 Settings → Pages 中启用 GitHub Pages
3. 选择 `main` 分支和根目录
4. 访问 `https://yourusername.github.io/repo-name/`
